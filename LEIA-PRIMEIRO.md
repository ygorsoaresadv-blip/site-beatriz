# Pacote do site da Beatriz

| Pasta/arquivo | Para quê |
|---|---|
| `PROMPT-INICIAL.md` | O texto para colar no Claude Code |
| `CLAUDE.md` | Instruções completas (o Claude Code lê sozinho) |
| `prototype/` | Protótipo aprovado: abra `prototype/index.html` no navegador |
| `design/` | Tokens de cor/tipografia e regras de identidade |
| `content/` | Textos, áreas, perguntas frequentes e roteiros |
| `examples/` | Modelos prontos: Supabase, Function de leads, cabeçalhos, SEO, script de verificação |

Para ver o protótipo localmente (os arquivos usam caminhos relativos): na pasta `prototype/`, rode `python3 -m http.server 8000` e abra `http://localhost:8000`.
